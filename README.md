---

# Instalimi

## 1. Clone Repository

```bash
git clone https://github.com/geraldo-matraku/se2026-RateBase-angular
```

---

# Setup Frontend

```bash
npm install
npm start
```

Frontend do të startojë në:

```bash
http://localhost:4200
```
